---
title: Implement
description: Implement the agreed request, plan, specification, or GitHub issue.
---

`implement` resolves the agreed contract from the request, plan, specification,
or supplied issue. An issue is optional; when supplied, it is read in full.

## Behavior

- Change only the agreed scope.
- Prefer the smallest coherent implementation.
- Run focused checks throughout and broader relevant checks at the end.
- Record safe reversible assumptions when autonomous mode is active.

## Boundary

Implementation reports the diff, checks, and remaining uncertainty. Passing
static checks is not runtime verification.

```bash
/implement https://github.com/owner/repo/issues/123
```
