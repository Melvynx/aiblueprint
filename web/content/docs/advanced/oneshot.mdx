`oneshot` is the opinionated complete workflow:

```text
analyze -> plan -> implement -> code-review -> verify
```

## Flags

| Flag | Behavior |
| --- | --- |
| `-a`, `auto` | Continue without confirmation unless authority, credentials, or an irreversible decision is missing. |

```bash
/oneshot -a add organization invitations
```

OneShot always runs review and verification. Failures are fixed and every
affected downstream stage runs again. The implementation plan is the source of
truth. A GitHub issue is optional for focused work; when this run creates one,
OneShot closes it only after verification passes. It remains open when any
criterion is blocked or not proven.
