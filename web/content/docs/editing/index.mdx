You film one take facing the camera, your AI agent turns it into an edited
short: word-by-word captions, "paper" motion design, music, sound effects, your
CTA. In your style, not someone else's.

The Editing IA Pro kit is a set of skills for Claude Code (and Codex) that
covers the whole chain: find the ideas that work, write the scripts, record on
the teleprompter, edit, publish, then retry what did not land.
