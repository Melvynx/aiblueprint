`verify` checks a change, fix, behavior, artifact, or external state through current evidence from its authoritative surface. It does not complete while anything is unproven.

## Invoke

```bash
$verify issue 123
```

## What it does

- Runtime proof, not “the tests passed on my machine” as a vibe.
- Last stage of `oneshot`. Independent of `code-review`.
- Use it whenever the user asks to prove, check, or demonstrate something.
