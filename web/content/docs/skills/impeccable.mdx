`impeccable` routes production-grade frontend work: design, redesign, audit, polish, animate, colorize. Not for backend-only tasks. Real working code, committed design choices.

## Invoke

```bash
$impeccable polish the pricing section
```

## What it does

- Loads `PRODUCT.md` / `DESIGN.md` via the skill context script before touching UI.
- Subcommands (`craft`, `shape`, `audit`, `polish`, …) each have a reference flow. Read it.
- Contrast, type scale, and existing tokens beat generic AI blue. Design systems already in the repo win.
