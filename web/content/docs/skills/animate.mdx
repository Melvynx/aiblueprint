`animate` is the single animation skill. Modes live as internal references (CSS, Motion for React, review, performance, accessibility, variants). Distilled from Emil Kowalski's animations.dev course.

## Invoke

```bash
$animate
```

## What it does

- Decide whether it should animate at all before writing a transition. High-frequency keyboard actions stay instant.
- Pick the smallest mode: CSS, Motion for React, review, improve, motion brief, performance, accessibility, or prototype variants.
- Motion is a spice. If everything animates, nothing stands out.
