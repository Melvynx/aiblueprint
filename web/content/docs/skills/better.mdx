`better` runs a cross-discipline UI review. It routes the screen to internal domain guides, then consolidates one ranked verdict. Evidence, not taste.

## Invoke

```bash
$better review the checkout flow
```

## What it does

- Resolve the screen or flow first. Cap at 15 findings. Narrow if the surface is too large to inspect honestly.
- Change-scoped review of diffs and PRs belongs to `interface-review`, not here.
- Approve only what was actually inspected. A short real report beats a padded one.
