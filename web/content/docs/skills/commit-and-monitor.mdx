`commit-and-monitor` commits, pushes, then monitors CI and the project's deploy. It auto-fixes failures and retries until the ship is actually green.

## Invoke

```bash
$commit-and-monitor
```

## What it does

- Use when the commit is not done until CI and the deploy agree.
- Reads real check and deployment status. Does not assume push equals success.
- Keeps iterating on failures instead of dumping a red link in chat.
