`brainstorm` is progressive research with parallel agents, skeptical analysis, and multi-perspective synthesis. Use it when you need battle-tested conclusions, not a first-pass summary.

## Invoke

```bash
$brainstorm
```

## What it does

- Diverge first. Do not converge on a take until competing frames have been stressed.
- Runs parallel exploration, then a skeptical pass that tries to kill weak conclusions.
- Output is a decision-ready synthesis, not a pile of notes.
