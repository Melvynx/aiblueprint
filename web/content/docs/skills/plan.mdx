`plan` consumes an analyzed request and produces an implementation-ready plan. It stops before writing code.

## Invoke

```bash
$plan use the current analysis
```

## What it does

- Optional GitHub issue for focused work. Read it in full when supplied.
- Does not implement. That is `implement`.
- The plan becomes the source of truth for `oneshot` and later stages.
