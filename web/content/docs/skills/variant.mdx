`variant` answers “which of these?” rather than “is this right?”. It builds several different versions of one piece of UI behind a picker in the actual page so you can flip and promote the winner.

## Invoke

```bash
$variant
```

## What it does

- Variants must be genuinely different, not opacity tweaks of the same layout.
- They live in the real page, not a disconnected sandbox.
- Promote the winner and delete the rest. Do not ship the picker.
