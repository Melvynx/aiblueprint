`show-me` helps you understand the current topic visually: concise diagrams, code-shape sketches, and small HTML artifacts. Use it when prose is the wrong medium.

## Invoke

```bash
$show-me
```

## What it does

- Prefer a small diagram over another paragraph of explanation.
- Code-shape sketches show structure without dumping a whole file.
- Pairs with `use-artifacts` when the visual needs to become a reusable local page.
