`copywritting` (skill id keeps the original spelling) writes, rewrites, and sharpens emails, headlines, hooks, landing pages, ads, VSLs, CTAs, and offers.

## Invoke

```bash
$copywritting
```

## What it does

- Preserve the author's voice and factual claims. Do not invent proof.
- Use it for persuasion-focused editing, not generic blog filler.
- Invoke as `$copywritting` even though the title is Copywriting.
