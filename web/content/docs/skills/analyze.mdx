`analyze` inspects the repo, current behavior, constraints, risks, and nearby prior art. It stops when the request is understood well enough to plan.

## Invoke

```bash
$analyze add organization invitations
```

## What it does

- Produces evidence, constraints, risks, and measurable acceptance criteria.
- Does not write a plan, open an issue, or edit code.
- First stage of the Premium core workflow and of `oneshot`.

## Install

Included in Premium. Install or refresh with:

```bash
npx aiblueprint-cli@latest agents pro setup
```
