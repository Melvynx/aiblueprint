`audit-memories` is explicit-only. It audits and cleans agent-facing Markdown in the current project. Never selected implicitly.

## Invoke

```bash
$audit-memories
```

## What it does

- Run only from `$audit-memories` or `/audit-memories`.
- Compares agent docs to current project truth and deletes stale instructions.
- Pairs with [Don't overflow memory](/concepts/dont-overflow-memory).

## Install

Included in the free bundle:

```bash
npx aiblueprint-cli@latest agents setup
```

Install only this skill:

```bash
npx skills@latest add Melvynx/aiblueprint --skill audit-memories
```
