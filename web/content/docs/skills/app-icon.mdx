`app-icon` generates a premium, dimensional launcher icon for Expo / React Native, then post-processes it for App Store, Play Store, and favicon specs.

## Invoke

```bash
$app-icon a dimensional lemon mascot
```

## What it does

- Target a glossy 3D mascot or bold symbolic object on a full-bleed branded background, not a flat pictogram.
- Works with Codex `image_gen`, Nano Banana, gpt-image, or any image-generation tool.
- Argument hint: `[app concept or brand]`.

## Install

Included in the free bundle:

```bash
npx aiblueprint-cli@latest agents setup
```

Install only this skill:

```bash
npx skills@latest add Melvynx/aiblueprint --skill app-icon
```
