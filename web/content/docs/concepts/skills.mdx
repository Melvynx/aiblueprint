Skills are reusable workflows that Claude Code and Codex can invoke. AIBlueprint
installs the free bundle into the shared `~/.agents/skills` folder. Premium
setup adds the rest.

The full catalog, with a PRO badge on Premium skills, lives under
[Skills](/skills).

## Main feature workflow

Choose a workflow based on the task:

- **`apex`** is included in the free bundle. It runs an adaptive Analyze → Plan → Execute → eXamine loop with resumable checkpoints, risk-based review, and validation. See [Apex](/skills/apex).
- **`oneshot`** is a Premium router that runs `analyze → plan → implement → code-review → verify` in order. See [OneShot](/skills/oneshot).

Use `apex -a -x` for low-interaction implementation with adversarial review,
or `oneshot -a` for the complete fixed sequence.

See [The Core Workflow](/core-workflow) for stage ownership, then
[Advanced Workflows](/advanced) for flags and automation.

## Manual utilities

These maintenance skills run only when you invoke them explicitly. Claude and
Codex are both configured to prevent implicit selection.

- [`audit-memories`](/skills/audit-memories) — clean agent-facing project Markdown against current project truth.
- [`audit-skills`](/skills/audit-skills) — audit usage, duplicates, invocation controls, and scope.

## How they are organized

Each skill is a folder containing a `SKILL.md` file, and often a `references/`
folder with supporting guides. Because they live in `~/.agents/skills`, every
linked tool shares the same skills.

Install with [agents setup](/commands/agents-setup). Premium skills need
[agents pro setup](/commands/pro-setup). Use [agents unify](/commands/unify) to
centralize skills you already have.

See [Use Style](/skills/use-style), [Use Artifacts](/skills/use-artifacts),
[Don't overflow memory](/concepts/dont-overflow-memory), and
[Examples](/examples).
