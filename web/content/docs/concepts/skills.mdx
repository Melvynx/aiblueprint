Skills are reusable workflows that Claude Code and Codex can invoke. AIBlueprint
installs the free skill bundle into the shared `~/.agents/skills` folder.

## Main feature workflow

Choose a workflow based on the task:

- **`apex`** is included in the free bundle. It runs an adaptive Analyze → Plan → Execute → eXamine loop with resumable checkpoints, risk-based review, and validation.
- **`oneshot`** is a Premium router that runs `analyze → plan → implement → code-review → verify` in order.

Use `apex -a -x` for low-interaction implementation with adversarial review,
or `oneshot -a` for the complete fixed sequence. OneShot uses the implementation
plan as its source of truth; a GitHub issue is optional for focused work.

See [The Core Workflow](/core-workflow) for stage ownership and direct skill
invocation, then [Advanced Workflows](/advanced) for Apex and OneShot flags,
automation, and persistent screenshot-backed verification.

## Manual utilities

These miscellaneous maintenance skills run only when the user invokes them
explicitly. Claude and Codex are both configured to prevent implicit selection.

| Skill | Command | Purpose |
| ----- | ------- | ------- |
| `audit-memories` | `$audit-memories` | Audit or clean agent-facing project documentation against current project truth. |
| `audit-skills` | `$audit-skills` | Audit observed skill usage, duplicate discovery, invocation controls, and global-versus-project scope. |

## Premium skills

[Premium setup](/commands/pro-setup) adds the core workflow (`analyze`, `plan`,
`implement`, `code-review`, `verify`, and `oneshot`) and additional skills such
as `impeccable`, `better`, `animate`, and `use-artifacts`.

The installed catalog depends on your bundle and version. Use the assistant's
skill picker to inspect the skills available after setup.

## How skills are organized

Each skill is a folder containing a `SKILL.md` file, and often a `references/`
folder with supporting guides. Because they live in `~/.agents/skills`, every
linked tool shares the same skills.

## Installing

Skills are installed by [agents setup](/commands/agents-setup). Use
[agents unify](/commands/unify) to centralize global skills you already have
into `~/.agents`, or `agents unify projects` to move project-local skills into
that repository's `.agents/skills` folder.

See [Use Style](/concepts/use-style) for the visual system, [Use Artifacts](/concepts/use-artifacts)
for reusable local HTML experiences, [Don't overflow memory](/concepts/dont-overflow-memory)
for keeping agent memory small, and [Examples](/examples) for the live style picker.
