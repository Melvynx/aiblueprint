---
title: Analyser
description: Comprendre le changement demandé sans planifier ni modifier d'état.
---

`analyze` inspecte le dépôt, le comportement actuel, les règles, les
contraintes, les risques et l'existant voisin.

## Sortie

- Le problème et le comportement souhaité.
- Les preuves de l'environnement actuel.
- Les contraintes et les risques matériels.
- Des critères d'acceptation mesurables.
- Les décisions qui ont vraiment besoin de toi.

## Frontière

Il s'arrête quand la demande est assez comprise pour planifier. Il ne crée
ni plan, ni issue, ni implémentation.

```bash
/analyze add organization invitations
```
