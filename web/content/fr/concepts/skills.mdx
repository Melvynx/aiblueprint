Les skills sont des workflows réutilisables que Claude Code et Codex peuvent
invoquer. AIBlueprint installe le lot gratuit dans le dossier partagé
`~/.agents/skills`. Le setup Premium ajoute le reste.

Le catalogue complet, avec un badge PRO sur les skills Premium, est dans
[Skills](/skills).

## Workflow de fonctionnalité principal

Choisis un workflow selon la tâche :

- **`apex`** est inclus dans le lot gratuit. Il lance une boucle adaptative Analyze → Plan → Execute → eXamine avec checkpoints reprenables, revue fondée sur le risque, et validation. Voir [Apex](/skills/apex).
- **`oneshot`** est un routeur Premium qui exécute `analyze → plan → implement → code-review → verify` dans l'ordre. Voir [OneShot](/skills/oneshot).

Utilise `apex -a -x` pour une implémentation peu interactive avec revue
adversariale, ou `oneshot -a` pour la séquence fixe complète.

Voir [Workflow principal](/core-workflow) pour la responsabilité des étapes,
puis [Workflows avancés](/advanced) pour les flags et l'automatisation.

## Utilitaires manuels

Ces skills de maintenance ne tournent que quand tu les invoques
explicitement. Claude et Codex sont configurés pour empêcher la sélection
implicite.

- [`audit-memories`](/skills/audit-memories) — nettoyer le Markdown agent du projet contre la vérité actuelle.
- [`audit-skills`](/skills/audit-skills) — auditer usage, doublons, contrôles d'invocation et scope.

## Comment ils sont organisés

Chaque skill est un dossier qui contient un `SKILL.md`, et souvent un dossier
`references/` avec des guides complémentaires. Comme ils vivent dans
`~/.agents/skills`, chaque outil lié partage les mêmes skills.

Installe avec [agents setup](/commands/agents-setup). Les skills Premium
passent par [agents pro setup](/commands/pro-setup). Utilise
[agents unify](/commands/unify) pour centraliser ceux que tu as déjà.

Voir [Utiliser un style](/skills/use-style),
[Utiliser des artefacts](/skills/use-artifacts),
[Ne pas overflow la mémoire](/concepts/dont-overflow-memory), et
[Exemples](/examples).
