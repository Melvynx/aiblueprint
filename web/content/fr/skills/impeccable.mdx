`impeccable` route le travail frontend production : design, redesign, audit, polish, animer, colorizer. Pas pour du backend-only. Du vrai code qui marche, des choix de design commités.

## Invoquer

```bash
$impeccable polish the pricing section
```

## Ce qu'il fait

- Charge `PRODUCT.md` / `DESIGN.md` via le script de contexte du skill avant de toucher l'UI.
- Les subcommands (`craft`, `shape`, `audit`, `polish`, …) ont chacune un flow de reference. Lis-le.
- Contraste, échelle typo et tokens existants battent le bleu IA générique. Le design system du repo gagne.
