`animate` est le skill d'animation unique. Les modes vivent en references internes (CSS, Motion for React, revue, perf, accessibilité, variants). Distillé du cours animations.dev d'Emil Kowalski.

## Invoquer

```bash
$animate
```

## Ce qu'il fait

- Décide si ça doit animer du tout avant d'écrire une transition. Les actions clavier haute fréquence restent instantanées.
- Prends le plus petit mode : CSS, Motion for React, revue, improve, motion brief, perf, accessibilité, ou prototype variants.
- Le motion est une épice. Si tout anime, plus rien ne ressort.
