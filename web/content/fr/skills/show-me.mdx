`show-me` t'aide à comprendre le sujet visuellement : diagrammes concis, croquis de forme de code, et petits artefacts HTML. Utilise-le quand la prose est le mauvais medium.

## Invoquer

```bash
$show-me
```

## Ce qu'il fait

- Préfère un petit diagramme à un autre paragraphe d'explication.
- Les croquis de forme de code montrent la structure sans dumper tout un fichier.
- Va avec `use-artifacts` quand le visuel doit devenir une page locale réutilisable.

## Installer

Inclus dans Premium. Installe ou rafraîchis avec :

```bash
npx aiblueprint-cli@latest agents pro setup
```

Voir [Configuration Premium](/commands/pro-setup).
