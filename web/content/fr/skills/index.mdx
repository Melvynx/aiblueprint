Les skills sont des workflows réutilisables installés dans `~/.agents/skills`.
Claude Code et Codex les invoquent. Le lot gratuit arrive avec le setup.
Premium ajoute le workflow principal plus du design, du marketing, du browser
et de la vérif.

Dans Codex, utilise `$skill-name`. Dans Claude Code, `/skill-name` marche aussi.

## Installation

Les skills gratuits s'installent avec [agents setup](/commands/agents-setup).
Les skills Premium s'installent avec [agents pro setup](/commands/pro-setup).

```bash
npx aiblueprint-cli@latest agents setup
npx aiblueprint-cli@latest agents pro setup
```

Un seul skill gratuit depuis le registry public :

```bash
npx skills@latest add Melvynx/aiblueprint --skill use-style
```

## Sur le disque

Chaque skill est un dossier avec `SKILL.md`, souvent plus `references/` et des
scripts. Comme ils vivent dans `~/.agents/skills`, chaque outil lié partage le
même catalogue. [agents unify](/commands/unify) centralise les skills que tu
as déjà.

Voir [Workflow principal](/core-workflow) pour la responsabilité des étapes,
[Avancé](/advanced) pour Apex et OneShot, et
[Ne pas overflow la mémoire](/concepts/dont-overflow-memory) pour garder les
fichiers always-on petits.
