`clean-code` applique naming, petites fonctions, pas de `any`, early returns et erreurs typées, plus des rules stack-specific pour React 19, Next.js 15/16, Zustand v5 et TanStack Query v5.

## Invoquer

```bash
$clean-code
```

## Ce qu'il fait

- Utilise-le pendant l'écriture ou la revue, pas comme une religion de cleanup après coup.
- Les rules stack-specific battent les slogans « clean code » génériques.
- Va avec `code-review` pour les verdicts spec/standards et `impeccable` pour le craft visuel.
