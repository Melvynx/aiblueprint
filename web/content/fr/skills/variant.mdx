`variant` répond à « laquelle de celles-là ? » plutôt qu'à « est-ce que c'est juste ? ». Il construit plusieurs versions différentes d'un morceau d'UI derrière un picker dans la vraie page, pour que tu flippes et promotes le gagnant.

## Invoquer

```bash
$variant
```

## Ce qu'il fait

- Les variants doivent être vraiment différents, pas des tweaks d'opacité du même layout.
- Ils vivent dans la vraie page, pas dans un sandbox déconnecté.
- Promote le gagnant et vire le reste. Ne shippe pas le picker.

## Installer

Inclus dans Premium. Installe ou rafraîchis avec :

```bash
npx aiblueprint-cli@latest agents pro setup
```
