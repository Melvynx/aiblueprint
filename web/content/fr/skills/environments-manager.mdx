`environments-manager` pose des environnements d'agents isolés par worktree git, pour que Claude, Cursor et Codex ne fuient pas d'état entre checkouts.

## Invoquer

```bash
$environments-manager
```

## Ce qu'il fait

- Repos worktree-ready, config d'env IDE, et câblage `dev.sh`.
- Scripts worktree-up / worktree-down pour que chaque checkout ait son env.
- Utile quand tu parallélises des features en worktrees et que les agents se marchent dessus.

## Installer

Inclus dans le lot gratuit :

```bash
npx aiblueprint-cli@latest agents setup
```

Installer uniquement ce skill :

```bash
npx skills@latest add Melvynx/aiblueprint --skill environments-manager
```
