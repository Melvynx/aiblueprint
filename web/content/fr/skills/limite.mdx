`limite` sert quand tu te prends ta limite Claude trop vite. Claude Code fait tout tourner sur le modèle de la session : sur Opus, même trouver un fichier ou renommer un import te bouffe ta limite, et le sous-agent Explore intégré hérite d'Opus lui aussi. Ce skill envoie le boulot facile sur Haiku et garde Opus pour la vraie réflexion.

## Invoquer

```bash
/limite
/limite --project
```

## Ce qu'il fait

- Écrit deux sous-agents en `model: haiku` : `Explore` (recherche dans le code sans rien modifier, il remplace l'Explore intégré) et `chores` (renommer, éditions d'une ligne, lancer une commande et résumer sa sortie).
- Ajoute une note `## Models` dans `CLAUDE.md` qui délègue la recherche et les corvées à ces agents, et garde le plan, le debug et les changements sur plusieurs fichiers sur Opus.
- Portée utilisateur (`~/.claude/`) par défaut, `--project` écrit dans `.claude/` et `./CLAUDE.md`.
- N'écrase jamais un agent existant sans montrer le diff d'abord.

<Callout type="info">
Redémarre Claude Code ensuite, puis vérifie `/agents` : Explore et chores doivent afficher Haiku tous les deux.
</Callout>

## Installer

Inclus dans le lot gratuit :

```bash
npx aiblueprint-cli@latest agents setup
```

Installer uniquement ce skill :

```bash
npx skills@latest add Melvynx/aiblueprint --skill limite
```
