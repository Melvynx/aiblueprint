`implement` exécute une requête, un plan, une spec ou une issue GitHub optionnelle avec une boucle de feedback serrée. Il ne revendique pas la preuve runtime.

## Invoquer

```bash
$implement https://github.com/owner/repo/issues/123
```

## Ce qu'il fait

- Le plan est la source de vérité. Une issue GitHub est optionnelle et lue en entier si fournie.
- Lance les checks statiques pertinents. La vérif runtime appartient à `verify`.
- Étape d'exécution dans `oneshot`.

## Installer

Inclus dans Premium. Installe ou rafraîchis avec :

```bash
npx aiblueprint-cli@latest agents pro setup
```

Voir [Configuration Premium](/commands/pro-setup).
