Tu filmes une prise face caméra, ton agent IA en sort un short monté :
sous-titres mot à mot, motion design « papier », musique, bruitages, ton CTA.
Dans ton style, pas dans celui d'un autre.

Le kit Editing IA Pro, ce sont des skills pour Claude Code (et Codex) qui
couvrent toute la chaîne : trouver les idées qui marchent, écrire les scripts,
tourner au prompteur, monter, publier, puis relancer ce qui n'a pas pris.
