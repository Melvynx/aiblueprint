---
name: grill-me
description: Grill the user in rapid batches to sharpen a plan, decision, or idea. Use when the user asks for Grill Me, wants a rigorous interview, or uses a grill trigger phrase.
disable-model-invocation: true
---

Stress-test the user's thinking until both sides share a precise, actionable understanding.

1. Resolve discoverable facts from the environment. Ask only decisions the user can make.
2. Recommend voice input: microphone is fastest; short answers keyed `1` through `10` are enough.
3. Ask exactly 10 numbered questions in one batch. Lead with the highest-leverage unresolved decisions. Include a concise **Recommended answer** on every question.
4. Invite one grouped reply. Accept terse answers, skips, or blanket acceptance of the recommendations.
5. Summarize what is established, investigate new facts, then ask the next batch. If fewer than 10 decisions remain, ask only those.
6. Present a compact decision brief: goal, scope, constraints, chosen approach, rejected alternatives, risks, and acceptance criteria.
7. Get explicit confirmation before acting on it.

Challenge assumptions. Compare credible alternatives. Match the user's language. Do not implement until the brief is confirmed.
