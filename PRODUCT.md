# Product

## Register

product

## Users

Developers configuring Claude Code, Codex, OpenClaw, and related AI coding
tools. They use the documentation while installing, updating, or operating
their local agent stack.

## Product Purpose

AIBlueprint CLI centralizes installation and maintenance instructions for a
shared AI coding configuration. The documentation should make commands and
workflow contracts easy to scan, copy, and verify.

## Brand Personality

Technical, direct, and dependable. The documentation should carry the same
focused product character as Lumail's developer documentation.

## Anti-references

Avoid generic marketing pages, oversized decorative typography, bright SaaS
gradients, excessive cards, and documentation shells with weak hierarchy.

## Design Principles

- Keep navigation visible and predictable.
- Put readable technical content ahead of decoration.
- Use hierarchy and restrained contrast to support scanning.
- Make commands, code, and workflow boundaries unmistakable.
- Preserve familiar documentation interactions across viewport sizes.

## Accessibility & Inclusion

Target WCAG AA contrast, visible keyboard focus, reduced-motion compatibility,
semantic navigation, and layouts that remain usable on narrow screens.
